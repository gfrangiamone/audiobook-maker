Was ist das M4B-Format?

M4B (MPEG-4 Audiobook) ist das Standard-Dateiformat für Hörbücher. Basierend auf dem MPEG-4-Container (gleiche Familie wie MP4-Video) ist M4B im Wesentlichen eine AAC-Audiodatei mit speziellen Funktionen für Hörbücher:

  • Kapitelmarker: Eingebettete Navigationspunkte zum Springen zwischen Kapiteln
  • Cover-Art: Das Buchcover ist in den Datei-Metadaten eingebettet
  • Lesezeichen: Hörbuch-Player merken sich Ihre Hörposition (auch geräteübergreifend mit iCloud)
  • Metadaten: Titel, Autor, Sprecher, Genre und Veröffentlichungsdatum sind in der Datei gespeichert
  • Variable Geschwindigkeit: Player können die Wiedergabe beschleunigen oder verlangsamen, ohne die Tonhöhe zu ändern

M4B ist das Format von Apple Books, Audible (Aax ist eine DRM-geschützte M4B-Variante) und den meisten Hörbuch-Apps auf iOS und Android.

Fazit: Wählen Sie M4B, wenn Sie Apple Books oder eine spezielle Hörbuch-App verwenden. Wählen Sie MP3, wenn Sie die Datei auf einem einfachen MP3-Player oder Autoradio abspielen müssen, das M4B nicht unterstützt.

M4B-Dateien mit Kapiteln erstellen — Kostenlos

Das Erstellen von M4B-Dateien erforderte früher komplexe ffmpeg-Befehle oder kostenpflichtige Software. Audiobook Maker automatisiert den gesamten Prozess:

  1. Laden Sie Ihr E-Book hoch (EPUB, PDF oder TXT) — Kapitel werden automatisch extrahiert
  2. Wählen Sie M4B als Ausgabeformat — das Tool erledigt alles: TTS-Erzählung, AAC-Kodierung, Kapitelmarker, Cover-Einbettung
  3. Laden Sie die M4B-Datei herunter — bereit zum Import in Apple Books oder jeden M4B-kompatiblen Player

Die generierte M4B verwendet AAC-Audio mit 64 kbps (optimiert für Sprache), enthält 1400×1400 Cover-Art und hat ordnungsgemäße iTunes-kompatible Metadaten-Tags. Jedes Kapitel erscheint als Navigationspunkt in Ihrem Hörbuch-Player.

M4B-Dateien abspielen

iOS / Mac: Apple Books (integriert) — Ziehen Sie die M4B in Books oder synchronisieren Sie via Finder/iCloud.

Android: Listen Audiobook Player, Smart Audiobook Player, Sirin — alle unterstützen M4B mit Kapiteln.

Windows: Apple Books (via iTunes), VLC Media Player, BookPlayer (Microsoft Store).

Linux: VLC, Cozy (GTK Hörbuch-Player).

Auto / Einfacher MP3-Player: Konvertieren Sie in MP3 — die meisten Autoradios lesen keine M4B-Dateien.

Häufig gestellte Fragen

Kann ich M4B in MP3 konvertieren?

Ja. Verwenden Sie Audiobook Maker für MP3-Ausgabe oder ffmpeg für eine bestehende M4B: ffmpeg -i buch.m4b -acodec libmp3lame -b:a 128k buch.mp3. Beachten Sie, dass Kapitelmarker bei der Konvertierung verloren gehen.

Kann ich eine M4B in Kapitel aufteilen?

Ja. Tools wie m4b-tool oder ffmpeg können M4B-Dateien an Kapitelmarkern aufteilen. Audiobook Maker kann auch einzelne MP3-Dateien pro Kapitel ausgeben, wenn Sie separate Dateien bevorzugen.

Welche Hörbuch-Apps unterstützen M4B?

Apple Books (iOS/Mac), BookPlayer (iOS), Listen Audiobook Player (Android), Smart Audiobook Player (Android), Bound (iOS), Sirin (Android), VLC (alle Plattformen) und Plex mit dem Audnexus-Plugin.

Welche Bitrate sollte ich für M4B-Hörbücher verwenden?

Audiobook Maker verwendet 64 kbps AAC, den Standard für Sprachinhalte. Sprache benötigt keine hohen Bitraten — 64 kbps AAC klingt identisch mit 128 kbps MP3 für Erzählungen, benötigt aber nur die halbe Dateigröße.
