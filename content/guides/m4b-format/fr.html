Qu'est-ce que le Format M4B ?

M4B (MPEG-4 Audiobook) est le format standard pour les livres audio. Basé sur le conteneur MPEG-4 (même famille que la vidéo MP4), le M4B est essentiellement un fichier audio AAC avec des fonctionnalités spéciales conçues spécifiquement pour les livres audio :

  • Marqueurs de chapitres : Des points de navigation intégrés vous permettent de sauter entre les chapitres
  • Couverture : La couverture du livre est intégrée dans les métadonnées du fichier
  • Signets : Les lecteurs de livres audio mémorisent votre position d'écoute (même entre appareils avec iCloud)
  • Métadonnées : Titre, auteur, narrateur, genre et date de publication sont tous stockés dans le fichier
  • Vitesse variable : Les lecteurs peuvent accélérer ou ralentir la lecture sans changer la tonalité

Le M4B est le format utilisé par Apple Books, Audible (Aax est une variante M4B protégée par DRM) et la plupart des applications de livres audio sur iOS et Android.

Comment Créer des Fichiers M4B avec Chapitres — Gratuitement

Créer des fichiers M4B nécessitait auparavant des commandes ffmpeg complexes ou des logiciels payants. Audiobook Maker automatise tout le processus :

  1. Téléchargez votre ebook (EPUB, PDF ou TXT) — les chapitres sont extraits automatiquement
  2. Sélectionnez M4B comme format de sortie — l'outil gère tout : narration TTS, encodage AAC, marqueurs de chapitres, intégration de la couverture
  3. Téléchargez le fichier M4B — prêt à être importé dans Apple Books ou tout lecteur compatible M4B

Le M4B généré utilise l'audio AAC à 64 kbps (optimisé pour la parole), inclut une couverture 1400×1400 et possède des balises de métadonnées compatibles iTunes. Chaque chapitre apparaît comme un point de navigation dans votre lecteur de livres audio.

Comment Lire les Fichiers M4B

iOS / Mac : Apple Books (intégré) — glissez le M4B dans Books ou synchronisez via Finder/iCloud.

Android : Listen Audiobook Player, Smart Audiobook Player, Sirin — tous prennent en charge le M4B avec chapitres.

Windows : Apple Books (via iTunes), VLC media player, BookPlayer (Microsoft Store).

Linux : VLC, Cozy (lecteur de livres audio GTK).

Voiture / Lecteur MP3 basique : Convertissez en MP3 — la plupart des autoradios ne lisent pas les fichiers M4B.

Questions Fréquentes

Puis-je convertir un M4B en MP3 ?

Oui. Vous pouvez utiliser Audiobook Maker pour générer une sortie MP3, ou utiliser ffmpeg pour convertir un M4B existant : ffmpeg -i livre.m4b -acodec libmp3lame -b:a 128k livre.mp3. Notez que les marqueurs de chapitres sont perdus lors de la conversion.

Puis-je diviser un M4B en chapitres ?

Oui. Des outils comme m4b-tool ou ffmpeg peuvent diviser les fichiers M4B aux marqueurs de chapitres. Audiobook Maker peut également produire des fichiers MP3 individuels par chapitre si vous préférez des fichiers séparés.

Quelles applications de livres audio prennent en charge le M4B ?

Apple Books (iOS/Mac), BookPlayer (iOS), Listen Audiobook Player (Android), Smart Audiobook Player (Android), Bound (iOS), Sirin (Android), VLC (toutes plateformes) et Plex avec le plugin Audnexus.

Quel débit binaire utiliser pour les livres audio M4B ?

Audiobook Maker utilise 64 kbps AAC, ce qui est le standard pour le contenu parlé. La parole n'a pas besoin de débits élevés — 64 kbps AAC sonne identique à 128 kbps MP3 pour la narration, mais utilise la moitié de la taille du fichier.
