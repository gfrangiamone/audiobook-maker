为什么要把 PDF 转成有声书？

课程讲义、教材、报告、公共领域小说、长篇文档……很多需要阅读的内容都是 PDF 格式。盯着屏幕看很快就会疲劳。把 PDF 转成有声书之后，通勤、健身或做饭时都能收听，眼睛也能休息。

使用 Audiobook Maker，可以直接在浏览器中免费把 PDF 转换为有声书：上传文件，选择自然的语音，下载带章节的 MP3 或 M4B。无需安装软件，也无需注册账号。

PDF 转有声书：分步说明

  1. 上传 PDF：把文件拖到上传区域（最大 50 MB）。系统会提取文字并划分章节。
  2. 检查章节：每个识别出的章节都会显示标题和长度。可以取消勾选目录、版权页或参考文献。
  3. 选择语音：50 多种语言、400 多种神经网络语音，包括多种普通话、粤语和台湾国语语音。先试听简短的预览，确认音色和语速。
  4. 选择格式：MP3（单个文件，或每章一个文件的 ZIP）、带章节和封面的 M4B，或私人播客订阅源。
  5. 生成并下载：进度条会显示处理进度。文档较长时，可以选择邮件通知，然后关闭页面。

朗读前会自动清理的内容

PDF 是为打印设计的，而不是为收听设计的。普通的屏幕阅读器会把每个页眉、页码和脚注都读出来。Audiobook Maker 会在朗读之前先整理文字：

  • 识别并删除在多页重复出现的页眉和页脚（书名、章节名、出版社）。
  • 页码和脚注不再打断朗读。
  • 在行末被连字符断开的单词会重新拼合（适用于西文文本）。
  • 跳过图表说明文字、索引、网址、ISBN 和 DOI。
  • 括号内的文字默认不朗读，可在高级选项中重新开启。

章节是如何识别的

为了避免生成一个冗长的音频文件，工具会按以下顺序查找文档结构：

  1. PDF 的书签（如果有的话，这是最可靠的来源），
  2. 字号大于正文的标题，
  3. 带页码的目录页，
  4. 以上都没有时，整个文档作为一个章节朗读。

提示：如果这本书也有 EPUB 版本，请优先使用 EPUB。EPUB 中的章节和段落标记更规范，效果通常更好。参见 EPUB 转有声书指南。

PDF 转 MP3 还是 PDF 转 M4B？

MP3 可以在任何手机、车载音响和电脑上播放。对于讲义或文章，这是最简单的选择。

M4B 是经典的有声书格式：单个文件，包含章节标记、封面和断点续听。Apple Books 和大多数有声书应用可以直接跳到下一章。整本书建议选择 M4B。详见 M4B 格式指南。

  • 工作：在通勤途中听完报告、研究和手册。
  • 阅读障碍或视力不佳：收听更轻松，MP3 可以随时倒回重听。
  • 经典作品：公共领域作品可以免费下载 PDF 或 EPUB。我们的免费电子书网站列表介绍了合法获取的途径。

扫描版 PDF：先做 OCR

有些 PDF 只包含图片，例如扫描的书籍或拍照的页面，里面没有可供朗读的文字。上传时 Audiobook Maker 会提示这一点。请先对文档进行文字识别（OCR），然后上传识别出文字的版本。

常见问题

可以免费把 PDF 转成有声书吗？

可以。使用标准语音转换是免费的，无需账号，也无需安装。每月有充足的免费额度，足够转换许多本书。

语音听起来自然吗？

这些是神经网络语音，会按整句处理语调，而不是逐字朗读。建议先试听两三种语音，再生成整个文档。

转换需要多长时间？

取决于文字量。一篇文章几分钟就能完成，一本 300 页的书通常不到一小时。不必等待：即使关闭页面，服务器上的处理也会继续。

手机上能用吗？

可以，在手机、平板或电脑上的任何现代浏览器中都能使用。完成的 MP3 或 M4B 可以直接下载到设备上。

可以转换有密码保护的 PDF 吗？

只有在您有权解除保护并先解除之后才可以。工具只读取 PDF 允许访问的文字。
