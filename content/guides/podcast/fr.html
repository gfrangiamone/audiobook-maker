Transformez Votre Livre Audio en Podcast Privé

Audiobook Maker génère, avec les fichiers audio, un package podcast complet avec un flux RSS 2.0. Pour le rendre disponible comme podcast, les fichiers doivent être publiés sur un serveur web accessible depuis Internet. La solution idéale est votre propre site web ou espace d'hébergement. Alternativement, pour un usage personnel ou le partage avec quelques amis, vous pouvez utiliser une solution gratuite comme Netlify, décrite dans ce guide.

Usage recommandé : cette solution est conçue pour un usage personnel ou le partage avec la famille et les amis. Netlify offre 100 Go/mois de bande passante gratuite — largement suffisant. Pour une distribution publique, envisagez d'utiliser votre propre hébergement web.

Pas à Pas : Publiez Votre Livre Audio comme Podcast

  1. Générez le livre audio au format M4B — Dans Audiobook Maker, téléchargez votre fichier EPUB ou PDF, choisissez la langue et la voix, puis sélectionnez M4B comme format de sortie. L'outil crée un fichier M4B unique avec chapitres intégrés et couverture — le standard professionnel pour les livres audio.
  2. Générez aussi le package Podcast RSS — Après avoir généré le M4B, relancez la génération en mode Podcast RSS pour obtenir un ZIP contenant le fichier XML du flux RSS et les fichiers MP3 individuels des chapitres (les podcasts nécessitent un fichier audio par épisode).
  3. Créez un compte Netlify gratuit — Allez sur app.netlify.com et inscrivez-vous avec email ou GitHub. Aucune carte de crédit requise. Le forfait gratuit inclut 100 Go de bande passante, 10 Go de stockage et HTTPS automatique.
  4. Téléchargez sur Netlify — Dans le tableau de bord Netlify, sous Sites, faites glisser le dossier extrait entier sur la zone de dépôt en pointillés. Le site sera en ligne en quelques secondes. Renommez-le depuis Site configuration → Change site name (ex. mon-livre-audio.netlify.app).
  5. Vérifiez le flux — Ouvrez l'URL du flux dans votre navigateur :
    https://votre-nom-site.netlify.app/podcast.xml
    Si vous voyez du contenu XML avec les titres de vos chapitres, votre podcast est en ligne et prêt !

Pourquoi Écouter Votre Livre Audio comme Podcast ?

  • Signets automatiques — Reprenez exactement là où vous vous étiez arrêté, même entre différents appareils
  • Ordre des épisodes — Les chapitres sont lus dans l'ordre avec passage automatique au suivant
  • Métadonnées complètes — Couverture, titres des chapitres et infos sur le livre visibles dans votre app podcast
  • Vitesse réglable — Écoutez à 1,5x, 2x ou toute vitesse de votre choix, avec minuteur d'arrêt
  • Streaming — Pas besoin de télécharger tous les fichiers ; écoutez chaque chapitre en streaming
  • Partagez avec la famille — Envoyez l'URL du flux aux membres de la famille ; ils n'ont pas besoin d'un compte Netlify

Conseils pour la Publication de Podcast

  • Mettre à jour les épisodes : Re-téléchargez les fichiers sur Netlify pour remplacer la version précédente. Votre app podcast détectera les changements à la prochaine actualisation.
  • Plusieurs livres : Créez un site Netlify séparé pour chaque livre audio afin de garder les flux organisés.
  • Limites de stockage : Le forfait gratuit Netlify inclut 10 Go de stockage (~12 livres audio complets). Supprimez les livres terminés pour libérer de l'espace.
  • Confidentialité : L'URL du podcast est techniquement publique (toute personne ayant le lien peut s'abonner), mais n'apparaîtra pas dans les annuaires de podcasts ou les moteurs de recherche. C'est "privé" dans le sens où il n'est pas indexé.
  • Domaine personnalisé : Netlify prend en charge les domaines personnalisés dans le forfait gratuit si vous souhaitez une URL personnalisée.

Questions Fréquentes

Netlify est-il vraiment gratuit pour héberger mon podcast ?

Oui. Le forfait Starter gratuit de Netlify inclut 100 Go/mois de bande passante et 10 Go de stockage. Pour un podcast de livre audio typique (10-20 épisodes, ~5 Mo chacun), c'est plus que suffisant pour un usage personnel. Si vous dépassez les limites, vous pouvez passer à Netlify Pro (19$/mois) ou utiliser votre propre hébergement.

Pourquoi utiliser le format M4B plutôt que MP3 pour le livre audio ?

Le M4B est le standard professionnel pour les livres audio. Un seul fichier M4B contient tous les chapitres comme marqueurs de navigation, la couverture intégrée et les métadonnées. Il est pris en charge par Apple Books, Audible et toutes les principales applications de livres audio. Le MP3 est excellent pour une compatibilité maximale, mais le M4B offre une bien meilleure expérience d'écoute avec la navigation par chapitres.

Puis-je soumettre mon podcast aux annuaires Apple Podcasts ou Spotify ?

Pas avec un flux Netlify privé. Apple Podcasts Connect et Spotify for Podcasters exigent des flux hébergés sur des plateformes approuvées avec des exigences spécifiques (taille de la pochette, catégories, etc.). L'approche Netlify est pour des podcasts privés personnels — idéale pour écouter vos propres livres ou partager avec des amis proches et la famille.

Que puis-je utiliser si je ne veux pas Netlify ?

Tout hébergement web statique fonctionne : GitHub Pages, Cloudflare Pages, Vercel ou votre propre serveur web. Téléchargez simplement le dossier du podcast extrait à n'importe quel emplacement accessible via le web et l'URL du flux RSS fonctionnera dans les applications de podcast. Netlify est recommandé car il est gratuit, rapide et ne nécessite aucune configuration.

Les applications de podcast peuvent-elles télécharger des épisodes pour l'écoute hors ligne ?

Oui. Une fois abonné au flux dans une application de podcast, vous pouvez télécharger des épisodes individuels pour l'écoute hors ligne, comme n'importe quel autre podcast. L'application gère automatiquement le téléchargement, la position de lecture et la suppression.
