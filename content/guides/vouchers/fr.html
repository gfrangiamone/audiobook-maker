Qu'est-ce qu'un bon ?

Un bon (ou coupon) est un crédit prépayé en euros à dépenser dans les services PREMIUM d'Audiobook Maker. Il porte un code comme ABCD-EFGH-JKLM, parfois avec un préfixe (PROMO-, GIFT-, SUB-), et il est lié à l'adresse e-mail à laquelle il a été délivré.

Pour créer un livre audio, aucun bon n'est nécessaire : avec les voix Standard, la conversion est gratuite. Le bon ne sert que lorsque vous choisissez un service payant.

Ce que vous pouvez payer avec un bon

  • Voix PREMIUM : les modèles proposés dans le sélecteur Modèle des voix PREMIUM.
  • Optimisation du texte par IA : demandée seulement pour les livres au-delà du seuil gratuit.
  • Traduction du livre par IA.
  • Voix échantillonnée : un livre audio lu avec votre propre voix (voir le guide du clonage vocal).

Chaque bon a sa propre liste de services, indiquée dans l'e-mail qui contient le code. Lorsqu'un bon comprend un modèle de voix, il couvre aussi l'optimisation du texte par IA payée avec ce même livre audio.

Bons de remboursement

Si un travail payé avec PayPal échoue, le montant vous revient sous forme de bon envoyé par e-mail. Si vous aviez payé avec un bon, le montant revient simplement sur le même code : pas de nouveau code ni d'e-mail. Si vous annulez vous-même une génération PREMIUM, le coût de la partie déjà générée est retenu et le reste vous est remboursé.

Bons de don

Pour un don de 5 € ou plus, vous recevez un bon de même valeur, envoyé par e-mail à l'adresse liée au don. Merci : les dons aident à couvrir les frais de fonctionnement et les nouvelles fonctions.

Bons d'abonnement

Chaque mois payé d'un abonnement comprend un bon PREMIUM valable 30 jours. Il appartient à votre compte : lorsque vous payez un service PREMIUM en étant connecté, il vous est proposé automatiquement et vous n'avez pas à copier le code. Vous le voyez aussi, avec son solde, sur la page de votre compte.

Bons de don et modèles de voix

Parmi les modèles de voix PREMIUM, un bon de don paie uniquement Audiobook Maker (VoxCPM2), voix échantillonnées comprises. Il en va de même pour les bons d'abonnement. Avant de lancer, ouvrez le sélecteur Modèle des voix PREMIUM et choisissez Audiobook Maker (VoxCPM2).

Avec un autre modèle, la fenêtre de paiement affiche « Ce bon n'est pas valable pour le service choisi ». Passez au modèle Audiobook Maker (VoxCPM2), ou payez ce modèle avec PayPal. L'optimisation du texte par IA, la traduction du livre et la voix échantillonnée peuvent toujours être payées avec un bon de don.

Utiliser un bon, étape par étape

  1. Préparez le livre comme d'habitude : envoyez-le, choisissez les chapitres et la voix ou le service PREMIUM.
  2. Lancez la génération, l'optimisation ou la traduction : la fenêtre de paiement s'ouvre avec le total.
  3. Choisissez l'onglet « Utiliser un bon ».
  4. Saisissez le code du bon et l'e-mail associé au bon, celui qui l'a reçu.
  5. Le bon est vérifié automatiquement et le solde disponible s'affiche. Confirmez et le travail démarre.

Vous êtes connecté à votre compte ? La fenêtre de paiement vous propose, déjà rempli, le bon de votre compte qui couvre le paiement.

Solde, expiration et remboursements

  • Réutilisable : si le travail coûte moins que le solde, le reste demeure sur le code jusqu'à l'expiration. La fois suivante, saisissez le même code.
  • Un bon par paiement : le solde doit couvrir la totalité du montant. Un bon ne se combine ni avec PayPal ni avec un autre bon. Si le solde ne suffit pas, sélectionnez moins de chapitres ou payez avec PayPal.
  • Expiration : les bons de remboursement durent 180 jours, ceux de l'abonnement 30 jours ; pour les autres, la date figure dans l'e-mail.
  • En cas de problème : lorsqu'un travail payé avec un bon échoue, le montant revient automatiquement sur le même bon.

Messages de la fenêtre de paiement

  • Bon introuvable : vérifiez le code. Hormis le préfixe, les codes ne contiennent jamais les lettres O et I ni les chiffres 0 et 1.
  • E-mail non correspondant : saisissez l'e-mail auquel le bon a été envoyé.
  • Ce bon n'est pas valable pour le service choisi : le bon ne comprend pas ce service ou ce modèle de voix. Consultez la liste dans l'e-mail du bon.
  • Solde insuffisant : le total dépasse le solde.
  • Bon expiré ou Bon déjà utilisé : le bon ne peut plus être dépensé.
  • Ce bon est lié à un autre compte : connectez-vous avec le compte auquel appartient le bon d'abonnement.
  • Trop de tentatives de vérification : par sécurité, les vérifications sont limitées. Attendez le temps indiqué et réessayez.

Questions fréquentes

Faut-il un bon pour convertir un livre gratuitement ?

Non. Les voix Standard sont gratuites et ne demandent ni bon ni compte. Les bons servent uniquement aux services PREMIUM.

Comment savoir ce qui reste sur mon bon ?

Saisissez-le dans l'onglet « Utiliser un bon » : le solde disponible s'affiche dès la vérification. Les bons d'abonnement apparaissent aussi, avec solde et expiration, sur la page de votre compte.

Quels modèles de voix puis-je utiliser avec un bon de don ?

Parmi les modèles de voix PREMIUM, uniquement Audiobook Maker (VoxCPM2), voix échantillonnées comprises. Il paie aussi l'optimisation du texte par IA, la traduction du livre et l'échantillonnage de la voix.

J'ai perdu l'e-mail avec le code. Que faire ?

Cherchez « Audiobook Maker » dans votre messagerie, dossier spam compris. Si vous ne le trouvez pas, écrivez-nous depuis la page d'assistance avec l'e-mail auquel le bon a été délivré.

Quelqu'un d'autre peut-il utiliser mon bon ?

Celui qui l'utilise doit saisir à la fois le code et l'e-mail auquel il a été délivré. Les bons d'abonnement ne fonctionnent que dans le compte auquel ils appartiennent.
